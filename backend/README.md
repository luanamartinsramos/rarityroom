# RarityRoom — Backend

Backend da aplicação **RarityRoom**, desenvolvido em **C# com ASP.NET Core**.

O backend é responsável pela autenticação dos usuários e pelo gerenciamento
dos produtos da plataforma.

## Tecnologias utilizadas

- C#
- .NET 10
- ASP.NET Core
- REST API
- JSON
- Swagger / OpenAPI
- Autenticação por Cookies
- CORS

## Autenticação

O sistema possui autenticação por cookies.

É possível:

- Cadastrar usuários
- Fazer login
- Fazer logout
- Consultar o usuário atualmente autenticado

O cookie utilizado pela aplicação é:


RarityRoom.Auth
